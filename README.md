# hmoskovitz_Final_Project
Contains data and notebooks for the my ATM533 final project

For my final project, I will analyzing satellite imagery and or model reanalysis data for locations in the Arctic that experienced a large wildfire. I will be assessing how surface albedo changes in the location of the fire after the fire clears away dark forest. I will assess changes in albedo during months will snow cover and sunlight (probably February, March, April). 

I have initially gathered blue sky albedo data from Earthdata (https://search.earthdata.nasa.gov/search?portal=above)
